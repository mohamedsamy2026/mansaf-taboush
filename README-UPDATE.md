# تحديث لوحة إدارة منسف طبوش — حذف الصور وترتيب الأقسام

## مهم: النسخة دي مبنية على New folder(4).zip

لم يتم تعديل تصميم واجهة المطعم أو ملفات صورها. التعديلات في لوحة الإدارة وبرمجة الصور فقط.

## تثبيت التحديث على Supabase الموجود بالفعل

**لا تعيد تشغيل ملفات SQL رقم 01 أو 02 أو 03**؛ أنت شغّلتهم من قبل بالفعل.

1. افتح Supabase → SQL Editor → New Query.
2. افتح `supabase/04_reorder_categories.sql` في VS Code.
3. انسخ كل محتواه إلى SQL Editor واضغط **Run**.
4. رسالة Success تعني أن وظيفة حفظ ترتيب الأقسام أُنشئت. لا تتطلب إعادة إنشاء جداول أو حذف بيانات.

## تشغيل النسخة الجديدة

1. فك ZIP في مجلد جديد.
2. انسخ ملف `.env` **من نسختك الحالية على جهازك** إلى جذر النسخة الجديدة بجوار `package.json`. لا تشارك هذا الملف.
3. نفّذ `npm install` ثم `npm run dev` داخل المجلد الجديد.
4. افتح `/admin` وسجّل بحساب الأدمن الموجود بالفعل. ليس مطلوبًا إنشاء حساب جديد.

## الحذف التلقائي للصور

- زر التنظيف اليدوي القديم **اتشال**.
- اختيار صورة جديدة يعمل معاينة محلية فقط؛ الرفع المضغوط إلى Storage يحدث عند الضغط على «حفظ».
- اختيار صورة ثم إلغاء التعديل **لا يرفع أي ملف** إلى Storage.
- بعد حفظ صورة جديدة، يحاول النظام حذف الصورة السابقة تلقائيًا بشرط أنها غير مستخدمة في وجبة أو شعار آخر.
- عند حذف وجبة أو قسم، تظهر رسالة تأكيد واحدة؛ وبعد الموافقة تُحذف البيانات من PostgreSQL وتُحذف الصور غير المشتركة تلقائيًا من Storage.
- إذا فشل حذف Storage بسبب الشبكة تظهر رسالة تنبيه، وتُحفَظ المهمة في متصفح الأدمن لمحاولة تلقائية جديدة عند تسجيل دخوله. هذا لا يضمن إزالة الملف في نفس اللحظة أثناء انقطاع الخدمة، لذا افحص Storage بعد الاختبار.

## ترتيب الأقسام

- من لوحة الأدمن → الأقسام، استخدم سهم «فوق» أو «تحت» بجانب القسم.
- يتم حفظ الترتيب مباشرة في قاعدة البيانات، ويستمر بعد تحديث الصفحة.
- أُزيل حقل كتابة رقم الترتيب من نموذج القسم.
- عند إضافة قسم جديد يظهر في آخر القائمة، ويمكن تحريكه بالأسهم.

## اختبارات سريعة

1. أضف قسمًا، حرّكه للأعلى، ثم حدّث الصفحة وتأكد أن الترتيب محفوظ.
2. أضف وجبة بصورة، اضغط حفظ، ثم راقب Storage.
3. بدّل الصورة واضغط حفظ؛ تأكد من حذف الصورة السابقة ما لم تكن مشتركة.
4. جرّب اختيار صورة ثم «إلغاء»؛ تأكد أنها **لم** تُرفع.
5. احذف الوجبة بعد تأكيد واحد، وتحقق من اختفاء الوجبة وصورتها من Supabase.

## التحقق الفني

تم إجراء مراجعة للأماكن المتغيرة وفحص صياغة ملفات JS/JSX بنجاح، لكن تعذّر اختبار `npm run build` كاملًا لأن تنزيل حزم npm لم يكتمل في بيئة إعداد الحزمة. نفّذ `npm run build` محليًا قبل النشر.
